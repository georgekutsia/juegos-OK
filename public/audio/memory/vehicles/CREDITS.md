# Sonidos de vehículos

Los archivos de esta carpeta proceden de Mixkit y se utilizan bajo su licencia para efectos de sonido. La reproducción en el juego se corta a los 3 segundos.

- `ambulance.mp3`: Ambulance siren US (Mixkit, id 1642)
- `car-horn.mp3`: Car double horn (Mixkit, id 719)
- `train-horn.mp3`: Distant train horn (Mixkit, id 1654)
- `helicopter-rotor.mp3`: helicopter.wav, por lezaarth (Freesound, id 232818), licencia CC0 1.0. Sustituye al antiguo efecto de avión.
- `airplane.mp3`: Jet plane hum flying (Mixkit, id 1574)
- `rocket.mp3`: Fast rocket whoosh (Mixkit, id 1714)
- `car-passing.mp3`: Passing car and urban ambience (Mixkit, id 1554)
- `boat-engine.mp3`: Motorboat on the sea (Mixkit, id 1183)
- `cart-wheels.mp3`: Bike wheel spinning (Mixkit, id 1613). Se usa para las ruedas del carrito, cochecito y bicicleta.
- `cement-mixer.mp3`: Concrete Mixer, por Breviceps (Freesound, id 464647), licencia CC0 1.0.
